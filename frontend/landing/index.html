Sistema de Gestão de Academia

Cadastro de planos, alunos e aulas, inscrições, upload de foto e atestado com miniatura automática e relatórios de ocupação, tudo rodando na AWS.

Acessar o sistema
  • Site estático no S3 e API Gateway (HTTP API)
  • Funções Lambda em Python na VPC, com banco MySQL privado no RDS
  • Upload por URL pré-assinada e miniatura gerada por evento do S3
